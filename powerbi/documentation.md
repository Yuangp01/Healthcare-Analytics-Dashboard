
# Power BI Dashboard

## Healthcare Admissions Executive Dashboard

Interactive Power BI dashboard built on the cleaned healthcare dataset
processed through Python and loaded into SQL Server.

### Dashboard Focus

- Patient demographics
- Encounter volume and utilization
- Healthcare costs
- Insurance coverage
- Provider performance
- Organization performance
- Claims and outstanding balances

### Data Pipeline

Raw healthcare data  
↓  
Python data cleaning and validation  
↓  
Cleaned datasets  
↓  
SQL Server relational model  
↓  
Power BI data model  
↓  
Executive dashboard

### Tools

- Power BI
- DAX
- Power Query
- SQL Server
- Python
- Pandas
